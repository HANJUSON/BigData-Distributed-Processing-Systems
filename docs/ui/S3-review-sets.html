  2. 2목록: 이름·종류·상태·진행 막대·완료/전체·만든 날짜. 진행 중이 위. 진행률은 v_set_progress가 준다.
  3. 3[⋯]: 마감(판정 잠김 안내)·삭제(세트 이름·항목 수, 판정·이력은 남는다는 안내) 확인 대화상자.
  4. 4판정 패널: 1–4 선택, Enter 저장 후 다음 미검수, N 건너뛰기. 기본 선택 없음. 판정 삭제는 5초 ‘되돌리기’.
