주석

  1. 1검색 결과 안 위치(12 / 1,284)와 이전·다음. 키보드 ←·→ 이동, Esc로 결과로 복귀(스크롤 위치 복원). 링크 복사.
  2. 2카메라 이미지: 원본 비율 유지, 박스 2 px 실선, 번호 라벨은 박스 왼쪽 위. 무시 영역은 회색 빗금, 기본 꺼짐.
  3. 3BEV(Canvas 2D): 관심 영역·좌표계는 F-6과 동일, 센서 위치·진행 방향·10 m 눈금. 점 색 = 높이 또는 반사 강도(viridis). 점군은 float32 바이너리(x, y, z, 반사 강도).
  4. 4객체 표: 열 머리로 정렬, ⚠ + 문구로 관측 부족(색만으로 전달 안 함), NULL 포인트는 “계산 안 함(3D 박스 무효)”.
  5. 5연결 강조: 표 행 · 2D 박스 · BEV 박스가 같은 번호·같은 클래스 색. 한 곳에 올리면 세 곳 강조, 클릭하면 선택 고정. 판정(DB 과목)은 검수자 선택 시에만 활성.
